## Environment

* Python >= 3.8.8
* Main libraries used in the notebooks: [NetworkX](https://networkx.org/), [PyTorch](https://pytorch.org/), and [PyTorch Geometric](https://pytorch-geometric.readthedocs.io/)
* Every notebook can be opened in [Google Colab](https://colab.research.google.com/) from the [Schedule]({{ site.baseurl }}/schedule/) page, so no local setup is required.

## Repository Layout

* `W*/SampleCode_*.ipynb`: code samples used in the lectures on every Tuesday
* `W*/PracticeCode_*.ipynb`: practices on every Thursday
* `W*/Assignment_*.ipynb`: weekly assignments (submit through e-class by the next Wednesday)
* `W*/Solution_*.ipynb`: solutions for the assignments (uploaded after the deadline)
