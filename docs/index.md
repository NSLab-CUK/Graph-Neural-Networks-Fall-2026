## Weekly Routine

* **Tuesday:** lecture with sample code (`SampleCode_*.ipynb`)
* **Thursday:** practice session (`PracticeCode_*.ipynb`) and the weekly assignment is released (`Assignment_*.ipynb`)
* **Next Wednesday:** assignment due on e-class. Solutions are uploaded after the deadline.

## Assignments

Submit every assignment through e-class before the deadline.
Assignments are graded A (10 points), B (8 points), C (6 points), or F (0 points if not submitted on time).
Late submissions are accepted, but the maximum grade for a late submission is B (8 points).
